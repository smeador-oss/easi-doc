# Agent Reference

This section is designed to be copied and provided to an AI agent (ChatGPT, Claude, Cursor, Copilot, etc.) so that it can help you create portals and content for easi-doc by writing files directly.

## How to Use This

1. Open the [File Structure Reference](file-structure-reference.md) page
2. Copy the entire contents of that page
3. Paste it into your AI agent's context (as a system prompt, a file, or part of your conversation)
4. Ask the agent to create portals, sections, and pages for your documentation needs

## What Your Agent Can Do With This

- Create complete portal folder structures with `portal.json` manifests
- Write markdown documentation pages in the correct format
- Generate JSON data catalog files that render as interactive table cards
- Understand the naming conventions and folder layout that easi-doc expects

## Important Notes

- The **content-index.json** file is auto-generated by the server. Your agent does not need to create it. Just place the folders and files correctly and restart the app.
- After placing files, restart easi-doc (or if running, the server will pick them up on the next request cycle).
- All portal folder names must be lowercase with hyphens (e.g., `hr-policies`, not `HR Policies`).
